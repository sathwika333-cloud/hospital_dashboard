# hospital_dashboard
Hospital Management Dashboard | Power BI

#Project Overview

This project showcases a Hospital Management Dashboard designed using Microsoft Power BI. It presents patient statistics, hospital billing, department-wise billing, and payment status.

#Project Objectives

i.Monitor the total number of patients.
ii.Analyze total hospital bills and payments received.
iii.Track pending payments.
iv.Compare billing across hospital departments.
v.Visualize payment status.

#Tools Used

i.Microsoft Power BI
ii.Data Visualization
iii.Data Analysis

#Dashboard Features

i.Total Patients
ii.Total Bill
iii.Amount Paid
iv.Pending Amount
v.Patient Target Gauge
vi.Department-wise Billing
vii.Patients by Department
viii.Payment Status
